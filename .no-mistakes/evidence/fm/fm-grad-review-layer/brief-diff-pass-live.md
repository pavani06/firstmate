## Running the rendered remote-backed command in a pooled clone whose local default branch is stale

worktree was freshened off `origin/main` and the pooled clone's local `main` is still at the old commit.

```console
$ git log -1 --format='%h %s' main       # the stale local default branch

$ git diff main...HEAD | fm-diff-assert.sh --diff - --claim change --note 'added one line to app.txt' --forbid-path state/ --max-files 1

  state/secret.env @@ -1 +1,2 @@

FAIL
  - forbidden path touched: 'state/secret.env' (forbidden prefix: state/)
  - too many changed files: 2 > 1
  ^ the stale base attributes another worker's state/secret.env to this task

$ git fetch origin main && git diff origin/main...HEAD | fm-diff-assert.sh --diff - --claim change --note 'added one line to app.txt' --forbid-path state/ --max-files 1
COVERAGE (hunks=1)
  app.txt @@ -1,2 +1,3 @@
NOTE: added one line to app.txt
PASS (files=1, +1/-0)
  ^ the base the brief now renders reports only this worker's own commit
```
